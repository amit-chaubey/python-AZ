# Python-AZ

Project Based hands-on topics

## Description

This repository contains hands-on Python projects and exercises covering various topics from A to Z.

## Getting Started

### Prerequisites

- Python 3.x
- pip

### Setup

1. Clone the repository:
```bash
git clone https://github.com/amit-chaubey/python-AZ.git
cd python-AZ
```

2. Create a virtual environment:
```bash
python3 -m venv venv
```

3. Activate the virtual environment:
```bash
# On macOS/Linux:
source venv/bin/activate

# On Windows:
venv\Scripts\activate
```

4. Install dependencies (if any):
```bash
pip install -r requirements.txt
```
